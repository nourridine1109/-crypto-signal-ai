# Crypto Signal AI – iPhone V2

Diese Version ist für eine schmale iPhone-Oberfläche optimiert.

## Lokal testen
pip install -r requirements.txt
streamlit run app.py

## Auf dem iPhone benutzen
Die App muss auf einem öffentlich erreichbaren Python/Streamlit-Host bereitgestellt werden.
Danach:
1. URL in Safari öffnen.
2. Teilen antippen.
3. "Zum Home-Bildschirm" wählen.
4. Die Crypto Signal AI erscheint als Icon auf dem iPhone.

Wichtig: Der ZIP-Ordner allein läuft nicht direkt auf iOS. Python läuft auf dem Server,
das iPhone zeigt die Web-App an.
